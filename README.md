# PM Toolkit

Free, open-access collection of 18 product management templates you can preview, download as Markdown, or save as PDF. No signup required.

## Templates

### Strategy & Planning
- Product Requirements Document (PRD)
- Product Roadmap
- Competitive Analysis
- OKR Template

### Feature Development
- Feature Spec
- User Story Map
- Technical Brief

### Agile & Sprints
- Sprint Planning
- Sprint Retrospective
- Backlog Prioritization (RICE + MoSCoW)

### Research & Discovery
- User Research Plan
- Interview Guide
- Survey Template

### Communication
- Stakeholder Brief
- Meeting Notes
- Status Update

### Launch & Operations
- Launch Checklist
- Go-to-Market Plan
- Post-Mortem / Incident Review

## Features

- **Search** — Filter templates by keyword
- **Category filters** — Browse by color-coded category
- **Preview** — Read the full template in a modal before downloading
- **Download .md** — Get an editable Markdown file
- **Download .pdf** — Print-friendly PDF via browser print dialog
- **Responsive** — Works on desktop and mobile
- **No dependencies** — Single HTML file, runs in any browser

## Usage

Open `pm-toolkit.html` in your browser. That's it.

Or clone and open:

```bash
git clone https://github.com/NSurawski/pm-toolkit.git
open pm-toolkit/pm-toolkit.html
```

## Tech Stack

- React 18 (via CDN)
- Tailwind CSS (via CDN)
- Marked.js for Markdown rendering
- No build step required
